# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, and assume good faith. Harassment, personal attacks, and publishing others' private information are not tolerated in issues, pull requests, discussions, or any project space.

Report conduct concerns privately to jdavis@pcprogramming.com. Reports will be reviewed and handled confidentially.
