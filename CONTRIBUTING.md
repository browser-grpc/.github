# Contributing

The repositories under this org are **generated public exports**. The source of truth is the development repository on GitLab:

https://gitlab.com/jdavis2/grpc-over-datachannels

Please open issues and merge requests there — changes made directly in a generated export are overwritten at the next release.

When you report a bug, include:

- The package and version (for example `grpc-dc` 0.42.0), language, and runtime (browser + version, or OS).
- A minimal `.proto` and the smallest call sequence that reproduces it.
- What you expected, what happened, and any status code or log output.

For questions about using the libraries, the main repository README and the per-language READMEs in each export are the best starting point.
